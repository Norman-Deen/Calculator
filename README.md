# 🧮 Console Calculator (C#)

A simple interactive calculator built with **C#** for the console.  
Supports basic arithmetic operations: addition, subtraction, multiplication, and division – with validation and clear user prompts.

---

## 📦 Features

- ✅ Input validation for numbers and operators
- ➕ Supports +, -, *, /
- 🔁 Recursive retry for invalid input
- 🧼 Clears screen after each step for better readability

---

## 🚀 How to Run

1. Make sure you have **.NET SDK** installed:  
   [Download .NET](https://dotnet.microsoft.com/download)

2. Clone this repo and run:

```bash
dotnet run --project Calculator/Calculator.csproj
```
